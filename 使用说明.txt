离线曲谱工具 · 第 5 版（印刷简谱图片识别）

打开“简谱图片转JSON与MIDI.html”，展开“简谱图片识别 → JSON / MIDI”。
1. 选择 PNG / JPG / WebP / BMP 清晰图片。支持端正、带竖直小节线的数字简谱，
   默认每组两个声部（双手），单行谱改成 1 个。当前一次处理一张图。
2. 按原谱填写曲名、BPM、1=调号、拍号。续页没有速度标记时需要参考首页；
   默认 120 BPM 只是录入起点，识别器不会从一个无速度标记的图片推知演奏速度。
3. 点击“识别这张图片”。自动读取 0–7、上下八度点、升降记号、减时线、附点、
   竖排和弦、延音线及灰色延续音，按小节安排双手同步。
4. 点击图片框定位小节。橙框为待核对形状，红框为拍数异常的小节。
   可直接在右侧表格修改数字/和弦、拍长、延续前音，增删格；保存这一小节的校正。
   例如 1' 为高八度，1, 为低八度，(135) 为和弦，0 为休止，- 为延音格。
5. 用“下一处提示”逐个核对；必要时勾选“已对照图片核对剩余提示”。
   拍数异常的小节必须修正，不能直接生成；弱起/不完整尾小节可放到文字简谱区处理。
   识别后的拍数正确不代表全部音高正确。
6. 点击“生成曲目并进入音符图”。使用现有试听、拖动/改时长、撤销重做等功能核对。
   “下载当前 JSON”导出游戏曲谱；下方“导出 MIDI”导出当前修改后的 21 键改编。
   “导出该曲原简谱 MIDI”保留识别稿的半音和原音域，不包含后续图上修改。
7. “识别结果放入文字简谱区”便于处理反复、跨页或复杂的人工修订。
8. 保存 .music-project 可保留识别结果、校正记录、未保存的校对表草稿和图上结果。
   原图不嵌入工程，只保存文件名与 SHA256；重开后选择同一原图，会恢复对照且保留校正。

识别范围与核对
这不是通用音乐 OCR；当前针对类似示例的清晰排版印刷简谱。
歪斜照片、手写、复杂连线、反复记号、装饰音或特殊排版可能需要手动修订，
未能解析的行内字符和不合拍数的结果会提示。不同字体、压缩和缩放也可能导致误读。
PDF 可继续作参考查看，若要自动识别，请先将页面导出清晰图片。
所有识别在本机浏览器完成，没有外部模型、音源、脚本或网络服务。

本次附带示例
“图片识别示例”内是用户提供《若能绽放光芒》第 2 页，第 29–60 小节片段，非全曲。
按同套首页的 1=C、160 BPM 制作；32 个小节、双手共 379 个演奏音符。
新识别结果与独立看图转写的音高、起点、松键逐项核对一致；两个形状提示已核对。
包含游戏 JSON、原简谱 MIDI、21 键 MIDI、单文件试听、工程及原图副本。
工程导入后重新选择随附原图，即可在识别表格中检查。
仅用此样本核对通过，不能理解为任意谱图都能无误自动转换。

离线曲谱工具 · 第 4 版（简谱 → JSON / MIDI）

这是整合版工具：简谱录入、图上编辑、试听调速、JSON 与 MIDI 双向转换放在同一个 HTML。
“简谱转JSON与MIDI.html”和“通用曲谱JSON调试器.html”均为空白整合版，单个文件即可断网使用。

简谱录入
1. 展开“简谱生成 JSON / MIDI”，粘贴数字简谱，或导入 TXT。可先点击“填入示例”尝试。
2. 按原谱填写曲名、BPM、调号和拍号。默认 120 BPM 只是可调整的录入起点。
3. 1 为中音 C4（1=C），1' 为高八度，1, 为低八度；#4 / b7 表示升降音。
4. 默认一个音一拍。1:2 是两拍，1/2 是默认音长的一半，1. 是附点，0 是休止。
   1 - 延长一个默认音长；1 ~ 1 延音连接，不再次按下。音值按四分音符一拍计算。
5. (135):2 是两拍和弦；[1(35)25]:1 在一拍内分四步，前一步先松键。
   {57} 只弹 5→7→5；(1{57}) 弹 1+5、7、5。键位版 (A{TE}) 弹 A+T、E、T。
6. 双手分行用 R: / L:，更多声部用 V1: / V2:；同序号小节同时演奏。
   用 | 分小节，默认不足补休止；第一小节可弱起。多于拍号容量的小节会报错。
   不写小节线时，各声部从零开始按各自明确音值依次排定。
7. 明确的头部可写 BPM=100、1=G、拍号=4/4、曲名=名字；注释写 //。
   仅支持这里列出的文本语法，遇到不认识的文字会指出行列，不能自动猜节奏。
8. 点击“生成并进入音符图”，新增可编辑曲目；再次生成不会覆盖当前曲目的图上修改。
9. 点击“下载当前 JSON”导出游戏曲谱；“导出 MIDI”导出图上当前 21 键改编。
   “导出该曲原简谱 MIDI”保留录入时原音域和半音，不包含后来在音符图做的修改。
10. 原简谱、转换报告和录入草稿随 .music-project 工程保存，报告不进入游戏 JSON。

图片 / PDF 对照
可导入 PNG/JPG/WebP/GIF/BMP/PDF 放在面板下方查看，配合录谱键盘输入音符。
图片不会自动转成曲谱；八度点、减时线等请按谱面录成对应音区和音长。
PDF 使用浏览器本地查看能力，建议 Edge 或 Chrome。原图/PDF 不嵌入工程，工程只记文件名，
重新打开时需再次选择参考文件；文本录谱与转换结果会保存。

21 键适配
原音先按八度折叠入 MIDI 48–83，再把半音映射到最近白键，等距向下。
同键同起点合并，同键重叠截短前音以保留重按。所有数量和音高示例在转换报告显示。
可取消“自动适配 21 键”，此时无法表示的音符会阻止生成，方便严格核对。
持键比例用于提前松键；琶音每步单独松键，和弦成员同起同止。
纯休止尾巴不增加游戏按键事件；原简谱 MIDI 会保留谱面总时长。

离线调速试听与 JSON 调试工具 · 第 3 版（MIDI 双向转换）

新功能：MIDI → 21 键 JSON，以及当前 JSON → MIDI
1. 导入 .mid/.midi 或拖入页面，展开“MIDI 导入与 21 键自动适配”。
2. 勾选需要的音轨，默认不勾选纯鼓轨，也会过滤混合轨中的鼓音（MIDI 通道 10）。
3. 默认无需设置即可自动修正音域：先按八度移入 C3–B5（MIDI 48–83），
   再将不能表示的升降音映射到最近白键，等距时向下。
   例如 C2→C3；C6→C5；C♯4→C4。结果是 21 键改编，可能改变原和声与音区。
4. 可选移调 -48 至 48 半音。这里的单位是 MIDI 半音，与图上“音高偏移键”不同。
5. 默认把 CC64 延音踏板计入持键时长；如想按原始松键时刻生成，可取消勾选。
6. 点击“生成 21 键曲谱”，会新增一首可编辑曲目；再次生成不会覆盖当前修改。
   修正报告列出八度/升降音调整、重叠截短和重复合并等数量及音高示例。
7. 在音符图或 JSON 中修改，点击“下载当前 JSON”导出游戏曲谱。
8. 点击播放器旁“导出 MIDI”生成 .mid，包含当前编辑与上方“调速 BPM”。
   原有 JSON 文件同样可直接导入，再导出 MIDI。

转换规则与边界
支持标准 MIDI 文件格式 0、1，PPQN 以及 SMPTE 时间分辨率；不合并格式 2 的独立乐段。
变速 MIDI 按原始速度表换算为实际秒数，再折算为单 BPM、480 ticks/拍。
因此原来的快慢变化保留在音符时刻中，但不再保留原始乐谱的变速标记与拍格。
同键同起点的音符合并，并保留最晚终点；同键不同起点重叠时，截短前音以保留重按。
缺失松键在谱尾补齐；零时长至少保留 1 tick。结果再次通过 D/U 配对校验。
JSON 不能保留 MIDI 的原始力度、音色、多轨、弯音或全部半音；导出的 MIDI 是当前 21 键改编，
统一为钢琴、单轨、固定力度，并非还原原 MIDI。保留原 MIDI 作为源文件。
导出使用标准整数微秒速度，BPM 存在极小舍入差；ticks 超过 32767 时自动折算为 480。
单个 MIDI 最大 20MB、256 轨、500000 事件、100000 音符；一次导入一份 MIDI 便于选轨。
工程保留转换后的曲谱和修正报告；如需重新选原 MIDI 音轨，请再次导入原 MIDI。

双击 HTML 即可在 Edge / Chrome 使用，不需要联网或旁边的文件。
“离线调速试听与JSON调试.html”内置第 9 批 12 首原曲谱，包括已修复琶音松键的《忘记时间》。
“通用曲谱JSON调试器.html”从空白开始，可导入任意兼容的 21 键 JSON。

音符图直接调试
1. 点击音符选中，拖动改变时间与音高；单选时拖左右边缘改变时长。
2. 从空白处拖出矩形框选，或切换“框选多个音符”模式；Shift+点击增减选择。
3. 多选后拖动其中一个，整组一起移动。双击空白新增，Delete 删除。
4. 展开“批量调整选中音符”，可整体偏移拍数、升降键位、缩放持键时长。
   勾选“同时缩放起点间距”可拉伸整段节奏，以最早选中音符为锚点。
   音高按 21 键位置移动：7 键为一个八度，并非 7 个半音。
5. “起点对齐吸附网格”只调整起点，保留各音符持键时长。
6. 复制/剪切后，设置试听“起点秒”，再粘贴。可以跨曲目粘贴；时间按目标曲目的 tick 与 BPM。
7. 图聚焦时支持 Ctrl+A/C/X/V、方向键、Delete、Ctrl+Z/Y（或 Ctrl+Shift+Z）。
   多选拖动/批量操作一次为一步撤销。直接编辑 JSON 或事件表会重置图上撤销历史。
   同键重叠、非法时间或超出音域会整批拦截，不会只改一部分。

原版对比
蓝色为保留，绿色为新增/改后，红色虚线为移除/改前，金色为选中。
按“按键+起点tick+终点tick”精确对比；移动或改时长计为移除旧音符并新增。
对比只统计音符与 BPM，曲名、说明等文字仍以 JSON 编辑区为准。

试听、校验与保存
保留调速、区间循环、暂停继续、D/U 配对检查、事件表编辑、补齐末尾松键。
合成音色用于听辨节奏，不向游戏发送按键。
“下载当前 JSON”输出游戏可导入的单曲文件，使用上方调速 BPM。
“保存工程”输出 .music-project：保留全部曲目、原版、未应用 JSON、事件表和视图设置。
工程不能直接放入游戏；下次用“导入 JSON / 工程”恢复。导入工程会替换整个当前工作区。
工程不保存音符图撤销历史、选中状态和音符剪贴板。
切换曲目保留未应用的 JSON 文本；未写回的事件表只保留在当前曲目，切换前请写回。

草稿自动恢复
浏览器允许本地存储时自动暂存，连尚未修好的 JSON 文本也会保留。
再次打开时，选择“恢复草稿”或“忽略旧草稿”；选择前不会覆盖旧草稿。
草稿依赖当前浏览器与 HTML 路径，移动文件、清理浏览器或无痕模式可能使它不可见。
空间不足时页面会提示；请保存工程作为可迁移的备份。
HTML 本身不会被浏览器改写，正式文件请通过下载保存。
